# Plan: Initial Project Roadmap

## Objective

Create `PRODUCT_ROADMAP.md` as the initial working roadmap for BukieBrainJobs.
It will be a baseline for comparison with the user's forthcoming roadmap, not a
final locked delivery plan.

## Confirmed constraints

- The current codebase is a mock-first web/mobile monorepo.
- Phase 1 must not introduce live authentication, database, verification,
  payment, notification, or real-time integrations.
- The roadmap must separate completed/scaffolded work, next mock UX work, and
  later integration/launch gates.
- No dates, budgets, or vendor commitments will be invented.

## Proposed document

1. State product outcome, operating principles, current baseline, and explicit
   non-goals.
2. Define sequential phases with scope, deliverables, exit criteria,
   dependencies, and risk controls.
3. Capture cross-cutting quality, trust-and-safety, accessibility, analytics,
   and release requirements.
4. List open decisions requiring product or business input.
5. Add a comparison protocol for reconciling the user's roadmap with this draft.

## Validation

- Verify all named phases respect the Phase 1 mock-only boundary.
- Confirm no dates, budgets, secret values, or claims of live integrations.
- Review the document against existing app screens, shared packages, and
  `DESIGN.md`.

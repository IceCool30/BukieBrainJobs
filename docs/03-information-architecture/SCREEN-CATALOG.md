# BukieBrainJobs Screen Catalog

**Document ID:** IA-001
**Version:** 1.0
**Status:** Planning baseline

This catalog records the current project estimate of the product surface area. It is a planning reference, not permission to implement every listed screen immediately.

## Estimated Product Surface

The project record estimates approximately 190 to 250 unique screens/pages across the product ecosystem.

| Module | Approximate Screens |
|---|---:|
| Marketing website | 20 to 25 |
| Authentication | 10 to 15 |
| Client application | 45 to 60 |
| BrainWorker application | 45 to 55 |
| Admin dashboard | 35 to 45 |
| Corporate portal | 20 to 30 |
| Shared screens | 15 to 20 |
| Total | 190 to 250 |

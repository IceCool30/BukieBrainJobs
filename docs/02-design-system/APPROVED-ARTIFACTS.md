## Historical Locked Design Decisions

- Corporate Modern and Premium Minimalism direction.
- Deep Navy `#001A41` is the primary brand and action system.
- Emerald `#296A4B` is strategic emphasis and must not become the dominant action color.
- Hanken Grotesk is used for display and headings.
- Inter is used for body and interface content.
- Desktop uses a 12-column grid.
- Tablet uses an 8-column grid.
- Mobile uses a 4-column grid.
- Maximum content width is 1280px.
- Standard gutters are 24px.
- WCAG 2.2 Level AA is the baseline accessibility target.
- Motion is subtle, purposeful, predictable and reduced-motion aware.
- Icons are outline-first, rounded and consistent in stroke treatment.

## Brand asset rule

Supplied BukieBrainJobs logo assets are authoritative. They must be used as provided. Antigravity must not regenerate, redraw, approximate, distort or recolor the approved logo.


## Revision policy

A foundational visual change requires an explicit Design System revision. Screen-level work must not silently modify DS-001 through DS-012.

## Locked Visual Direction

- Corporate Modern
- Premium Minimalism
- Deep Navy `#001A41` as primary brand/action color
- Emerald `#296A4B` as strategic emphasis and positive/success signaling
- Hanken Grotesk for display and headings
- Inter for body and interface content
- 12-column desktop grid
- 8-column tablet grid
- 4-column mobile grid
- 1280px maximum content container
- 24px standard gutters
- Approved spacing, radius, elevation, iconography and motion systems
- WCAG 2.2 AA accessibility baseline

## Authority Boundary

`DESIGN.md` remains the visual source of truth. This register records the approved system but does not replace the detailed source artifacts.

Screen-specific design may compose these rules, but it must not silently create a competing visual system.

If a future requirement genuinely requires a foundational change, create a new design-system revision and record the decision before using the new rule.

## Verification rule

An approved status does not mean a source is physically mirrored. Each artifact must be checked for source presence, version, status, and consistency with `DESIGN.md` before the foundation release is signed.

## Locked visual authority

The approved system uses Deep Navy `#001A41` as the primary brand/action system, Emerald `#296A4B` as strategic emphasis, Hanken Grotesk for display/headings, and Inter for body/interface content.

No agent may reinterpret these foundations without an explicit product/design decision.

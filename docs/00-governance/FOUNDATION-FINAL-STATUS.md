## Important scope boundary

Foundation completion means the repository governance and canonical-reference layer is ready for engineering handoff. It does not mean that product features are implemented, that every future module has a complete feature specification, or that production infrastructure has been deployed.

## Engineering rule

No agent may begin arbitrary application development from a broad instruction. Work must enter through an approved feature specification and follow the Feature Factory sequence:

Product specification → UX requirements (DESIGN.md) → Antigravity design & implementation → QA & verification.


## Known source conflict

The approved `DESIGN.md` visual system takes precedence over legacy green-primary examples in the older technical specification. Deep Navy `#001A41` is the approved primary brand/action color, with Emerald `#296A4B` used as strategic emphasis. This conflict must remain documented until the engineering token implementation is created.

## Handoff rule

Before implementing any feature, the assigned developer or agent must read `AGENTS.md`, the source-of-truth hierarchy, the relevant product specification, applicable design artifacts, relevant architecture/security/QA documents, and the current decision log.

If a required requirement is missing or materially ambiguous, stop and request clarification rather than inventing a product decision.

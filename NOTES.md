# Architectural & Code Quality Notes (Persistent Memory)

## MANDATORY CODE QUALITY & ARCHITECTURAL MINIMIZATION RULES
Every piece of code, script, configuration, chart, and tag generated must strictly adhere to:
1. **Code Simplification & Economy:** Minimize moving parts, native first, zero boilerplate, hyper-focused functions (<25 lines), maximum impact with minimum code.
2. **Anti-Spaghetti Constraints:** No premature abstractions, flat linear logic, return early to avoid deep nesting.
3. **Formatting & Documentation:** Zero obvious comments, comment ONLY the 'Why' for non-engineering decisions, no conversational filler in code outputs.

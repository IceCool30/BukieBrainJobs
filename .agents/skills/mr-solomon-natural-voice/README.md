# Mr. Solomon Natural Voice

A skill for any AI agent that works with Mr. Solomon Bukie. It explains how he talks and writes, and how the agent must behave when it writes for him, writes in his name, or talks to him while doing any task.

It is always on. It is not only for when someone asks for his voice.

## What it covers

- Two modes: writing as him, and talking to him
- Learning his voice from his own messages and posts, not only from the file
- A working method for any piece of writing: understand, settle the position, draft, critique, rewrite, check
- A list of AI tells to remove
- Guidance for X, WhatsApp, email, business and formal writing
- Strict facts discipline: nothing invented, nothing unconfirmed stated as fact
- Before and after examples
- Checks that use context first instead of stalling the work with questions

## What it enforces

- Simple, natural English
- Direct and firm tone without aggression
- No em dashes
- No fake enthusiasm or cheerleading
- No empty intensifiers or corporate filler
- No unsupported absolute claims
- No invented facts or feelings
- No apologetic padding
- No request echoing

## Installation

```bash
git clone https://github.com/IceCool30/mr-solomon-natural-voice-skill.git
```

Place the folder where your agent loads custom skills from. The skill has no tool-specific steps, so it works the same in any agent that reads SKILL.md files.

## When it triggers

Always, for any agent working with or for Mr. Solomon Bukie: replies to him, drafts, posts, messages, documents and any content written on his behalf.

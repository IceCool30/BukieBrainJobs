# Mr. Solomon Natural Voice

Write messages, arguments, replies, and personal statements in a direct, thoughtful, human voice.

This skill is used when you want a response that sounds like the user wrote it — clear, grounded, and free of AI-generated filler.

## What it enforces

- Simple, natural English
- Direct and firm tone without aggression
- No em dashes
- No fake enthusiasm or cheerleading
- No empty intensifiers
- No corporate filler openers
- No unsupported absolute claims
- No invented facts or feelings
- No apologetic padding
- No request echoing

## Installation

```bash
git clone https://github.com/IceCool30/mr-solomon-natural-voice-skill.git
```

Place the skill folder where your agent loads custom skills from.

## Triggering

Use when the user asks for a reply written in their voice, or when any message, argument, or personal statement needs to sound human and direct rather than generic AI output.

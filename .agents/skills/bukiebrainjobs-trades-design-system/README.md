# BukieBrainJobs Trades Design System Skill

> **Deprecated historical reference.** The rules below describe a retired Trades visual direction. Do not use this README or its examples for current UI work. Use `.agents/skills/bukiebrainjobs-outlier-design-system/SKILL.md` for web/PWA appearance and THEME-001 for theme mechanics. Native visual restyling remains separately scoped.

This skill provides the design tokens, the single dark theme (Obsidian Titanium Gunmetal), typography standards, and component reskinning guide for BukieBrainJobs.

## Purpose
Use this skill when restyling existing BukieBrainJobs interfaces, components, forms, and tables to match the approved design system aesthetic.

## Key Rules
1. **Reskin, Do Not Invent**: Update styles of existing components; do not inject unsolicited layout blocks (no unauthorized telemetry bars, requisition index tables, or hero manifesto banners).
2. **Dark Only**: Dark (`#0B0E13` canvas, `#13171E` cards) is the only approved theme on web, PWA and mobile. Never add light tokens, theme toggles, Appearance settings or saved theme preferences.
3. **Typography**: Pair `Cabinet Grotesk` (display headings), `Inter` (body copy), and `JetBrains Mono` (codes, currency, telemetry).
4. **Action Catalyst**: Reserve Molten Amber (`#FF6B35`) for primary call-to-action triggers.
5. **Trust Signals**: Reserve Brand Green (`#2FE896`) for verified status, escrow, and active indicators.
